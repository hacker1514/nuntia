Core Features

WhatsApp Aesthetic, Cellular Power

Everything you need for clean, private text messaging.

WhatsApp Theme

Emerald Teal and Dark Mode aesthetics with wallpaper backgrounds and checkmark indicators.

100% Local-First

Messages are stored exclusively in indexed SQLite tables on your device. Zero cloud sync.

Contact Management

Create, edit, and manage contact names & numbers with floating action controls.

Multi-part SMS

Native Kotlin SmsManager bridge handles long messages smoothly with delivery notifications.

Single-Tap Onboarding

Clean single "Grant" button onboard setup for standard Android SMS default role configuration.

Zero Glitch Transitions

Optimized Flutter state repositories prevent dashboard flashes when opening or closing chats.
