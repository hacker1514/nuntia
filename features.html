Features

Everything Nuntia Provides

A high-class offline messaging solution built with Flutter, Dart, and Kotlin.

WhatsApp Theme

Emerald Teal and Dark Mode palettes with custom chat wallpaper, bubble threads, double checkmark indicators, and floating green action buttons.

100% Local-First Storage

All conversations and messages are stored exclusively on your device in indexed SQLite database tables. Zero cloud sync or analytics tracking.

Cellular SMS Transport

Operates cleanly over carrier cell signals. Native Kotlin SmsManager handles multi-part messages seamlessly with status updates.

Contact Management

Create new chat threads by Name and Phone Number, edit existing contact names, or clear messages cleanly without friction.

Single-Tap Onboarding

Unified onboarding card with a single "Grant" action button to set Nuntia as the system Default SMS App smoothly.

Zero Glitch Navigation

State repository keeps conversation state cached during route transitions, eliminating list flashing when popping back to the dashboard.
