Nuntia Architecture & Docs

Learn how Nuntia handles offline cellular messaging, native Android SMS bridges, and SQLite database storage.

1. System Overview

Nuntia is designed as a privacy-first, local-first cellular SMS messenger for Android. Unlike typical modern messaging applications that require internet connectivity, cloud servers, or user accounts, Nuntia communicates directly with your mobile carrier's SIM network using native Android APIs.

The UI is crafted in Flutter with a high-class WhatsApp aesthetic, featuring Emerald Teal and Dark Mode palettes, interactive contact management, double checkmark indicators, and smooth state updates without list flashing.

2. Technical Architecture

Nuntia is split into three main architectural layers:

  • Flutter/Dart UI Layer: Manages chat lists, bubble thread screens, contact creation/editing, and theme state.
  • State & SQLite Repository Layer: Uses sqflite to maintain local indexed conversations and messages tables.
  • Native Android Bridge Layer (Kotlin): Invokes Android SmsManager for sending text messages and Listens to SmsReceiver broadcast intents for incoming text messages.

3. Android Permissions & Default Role

To handle SMS sending and receiving seamlessly on Android 4.4+ (API 19+), Nuntia requires default SMS app registration. When first opened, Nuntia displays a single-tap "Grant" onboarding screen which prompts the user to grant default messaging privileges. 

<uses-permission android:name="android.permission.SEND_SMS" />
<uses-permission android:name="android.permission.RECEIVE_SMS" />
<uses-permission android:name="android.permission.READ_SMS" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />

4. Native Kotlin SMS Bridge

When a user sends a message, Flutter invokes MethodChannel("com.nuntia.app/sms"). The Kotlin layer splits long messages using SmsManager.divideMessage() and sends them with pending status callbacks.

For incoming messages, SmsReceiver.kt reassembles raw SMS PDU fragments into complete text messages, inserts them into SQLite, and displays heads-up Android system notifications.

5. SQLite Local Storage Schema

Nuntia uses a local SQLite database named nuntia.db. It consists of two indexed tables:

  • conversations: Stores phone number, contact name, last message snippet, timestamp, and unread count.
  • messages: Stores message ID, conversation ID, body, direction (SENT/RECEIVED), status, and timestamp.

6. Building the Application

To compile Nuntia locally, run the following commands in your terminal:

git clone https://github.com/hacker1514/nuntia.git
cd nuntia
flutter pub get
flutter build apk --debug
